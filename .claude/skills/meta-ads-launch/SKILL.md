# Meta 광고 원클릭 런칭

`meta-ads` MCP 도구를 사용한다. 사용자는 브리프만 주고, 나머지는 이 순서대로 끝까지 자동으로 진행한다.
질문은 **필수 정보가 빠졌을 때 한 번에 묶어서**만 한다.

## 0. 입력 확인
필수: **상품/서비스**, **랜딩 URL(https)**, **목표**(판매/리드/트래픽/인지도), **일예산(원)**
선택(없으면 기본값): 지역(대한민국 전체), 기간(상시), 톤앤매너, 금지 표현, 브랜드 컬러, 제품 사진 경로

## 1. 계정 점검
`account_overview` → 계정 상태가 ACTIVE인지, 페이지·픽셀이 설정됐는지, 예산이 `max_daily_budget` 이하인지 확인.
- 판매/리드 목표인데 픽셀이 없으면: OUTCOME_TRAFFIC으로 바꾸고 사용자에게 알린다.

## 2. 리서치 (근거 없이 타겟을 짐작하지 않기)
- 랜딩 페이지를 읽어서 핵심 USP, 가격/혜택, 타겟 고객, 증거(후기, 수치)를 뽑는다 (WebFetch 또는 web-fetch 에이전트).
- 선택: 경쟁사가 집행 중인 광고를 Apify의 Facebook Ads Library 스크레이퍼로 조사해 반복되는 후킹 패턴을 파악한다.
- 결과는 페르소나 2~3개로 정리한다: 누가 / 어떤 문제가 있고 / 무엇을 원하는지 / 구매를 망설이는 이유.

## 3. 타겟 설계 — 광고세트 2~3개 (A/B 테스트 구조)
| 세트 | 구성 | 목적 |
|---|---|---|
| `브로드` | 연령·성별·지역만 지정, `advantage_audience: true` | Meta 알고리즘 기준선 |
| `관심사_<주제>` | 페르소나별로 `search_interests` 결과 3~6개를 `flexible_spec`에 묶기 | 가설 검증 |
| (선택) `관심사_<주제2>` | 다른 페르소나 | 비교 |

- 각 세트마다 `estimate_audience` 호출. MAU가 **10만 미만이면 관심사를 넓히고, 5천만 이상이면 연령을 좁힌다**.
- 관심사는 반드시 `search_interests`가 돌려준 실제 id만 사용한다. id를 지어내지 않는다.
- 일예산이 2만원 미만이면 광고세트는 2개까지만 만든다(학습 분산 방지).

## 4. 카피 소재 — 앵글 3개
앵글마다 서로 다른 심리를 건드려야 테스트가 의미 있다.
1. **문제/공감** — 고객의 고통을 정확히 짚는 첫 문장
2. **혜택/결과** — 구체적인 숫자, 전후 비교
3. **증거/오퍼** — 후기, 판매량, 한정 혜택, 긴급성

앵글별로 작성할 것:
- `primary_text`: 125자 이내. **첫 줄이 후킹**(스크롤을 멈추게 할 것), 이모지는 0~2개, 마지막 줄은 행동 유도
- `headline`: 25자 이내 권장(최대 40자)
- `description`: 30자 이내
- `cta`: 목표에 맞게 선택 — 판매 SHOP_NOW/BUY_NOW, 리드 SIGN_UP/GET_QUOTE/APPLY_NOW, 트래픽 LEARN_MORE

금지: 과장·허위 표현("100% 보장", "최고", 근거 없는 1위), 개인 특성을 지칭하는 문구("당신 탈모죠?" 같은 표현 — Meta 정책 위반), 건강·금융 관련 단정적 효과 주장.

## 5. 이미지 소재
앵글마다 `render_ad_image`를 1080x1080 크기로 1장씩 만든다.
- 이미지 헤드라인은 **15자 안팎의 짧고 굵은 메시지**로 쓴다(카피의 헤드라인과 달라도 된다)
- 사용자가 제품 사진을 주면 `bg_image_path`로 사용한다. 없으면 브랜드 컬러를 배경으로 쓴다
- 혜택이 있으면 `badge`로 표시한다(예: "첫 구매 30%")
- 만든 이미지는 Read로 직접 열어서 글자 잘림, 가독성, 대비를 확인하고 문제가 있으면 다시 생성한다

## 6. 원클릭 세팅
1. plan JSON을 구성한다. 이름 규칙: `<브랜드>_<목표>_<YYMMDD>`
2. `launch_campaign(plan, dry_run=true)` → errors가 있으면 고쳐서 다시 실행한다
3. 사용자에게 **요약표**를 보여준다: 예산, 광고세트별 타겟과 예상 도달 규모, 소재 3개(카피 + 이미지 경로), 생성될 광고 수
4. 바로 `launch_campaign(plan, dry_run=false)`를 실행한다. 모든 항목이 **PAUSED 상태로 생성되므로 과금은 없다**
5. 광고관리자 링크를 안내하고 묻는다: "지금 집행을 시작할까요?"
   - 사용자가 명시적으로 승인한 경우에만 `set_status(campaign_id, "ACTIVE", cascade=true, confirm=true)`를 실행한다

## 7. 마무리 안내
- 학습 기간(전환 약 50건 또는 3~7일)에는 예산과 타겟을 수정하지 않는다
- 3일 후 `/meta-ads-optimize`로 성과를 점검한다
